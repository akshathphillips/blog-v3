This is the third version of my website, and the first one I actually expect to keep.

Version one was an Angular Material blog with a light/dark toggle, a "Brews" section, the works. It was a fun way to learn Angular, but the framework was the point and the writing never happened. There was a version two somewhere in between that never left my laptop.

So version three goes the other way entirely. It's plain HTML built by a single Node script with zero dependencies, hosted out of an S3 bucket. There is no framework to upgrade, no build pipeline to babysit. If it still compiles in ten years (and it will, because there's nothing to compile), the words are what's left.

## What this place is

Not a résumé. Not a portfolio. I have LinkedIn for the first and GitHub for the second. This is an online presence in the older sense of the word: a place.

- **Writing**: stories about my life, things I'm building, what work actually looks like day to day.
- **Glimpses**: photos with a caption and no further explanation. A feed I own.
- **Bookmarks**: my universal bookmark bar, cool projects, recipes, rabbit holes. If I'd send it to a friend, it goes here.

The one thing I did carry over from version one is the color scheme: the warm orange on grey, and the dark mode toggle in the corner. Some things were right the first time.
